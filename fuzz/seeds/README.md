# Fuzz seeds

Valid modules the fuzzers start from. Everything here is either **generated by this
repository** or **written by the repository owner**; no third-party module is committed,
and none should be.

`cargo xtask fuzz --seed` copies these into the git-ignored working corpus, together with
the owner's S3Ms from `crates/starplayer-s3m/tests/fixtures/` and — when the conformance
cache is present — the MOD, S3M and MTM files of the pinned libxmp corpus. That last set
is **not ours to commit**, which is why seeding happens at run time out of the cache the
conformance job already maintains rather than by checking bytes in here.

`crates/starplayer-offline/tests/fuzz_seeds.rs` asserts on every commit that each file
below still loads as its own format, so a seed cannot rot into a file that only tests the
rejection path.

## `mod/`

| File | What it pins |
|---|---|
| `synthetic-golden.mod` | the C6a golden fixture: loops, both finetune directions, vibrato, panning, portamento, a speed change and a BPM change |
| `mk-minimal.mod` | the smallest well-formed `M.K.` file: one pattern, one sample, a two-word repeat |
| `mbang-kbang.mod` | `M!K!`, which ProTracker itself writes past 64 patterns (C3b) |
| `flt4.mod` | the Startrekker four-channel tag |
| `flt8-paired-halves.mod` | Startrekker `FLT8`: two 4-channel halves per pattern, order numbers halved |
| `chn5-single-digit.mod` | single-digit `5CHN` (C3b) |
| `chn8.mod` | `8CHN` |
| `chn16-two-digit.mod` | two-digit `16CH` |
| `order-tail-high-bytes.mod` | order bytes at or above `0x80` in the inactive tail, which must not raise the stored pattern maximum (C3b) |
| `zero-song-length.mod` | a zero song length: loads, plays nothing, still locates its sample data (C3b) |
| `one-word-repeat.mod` | a one-word repeat, which is a one-shot rather than a loop (C3b) |

## `s3m/`

| File | What it pins |
|---|---|
| `minimal.s3m` | two channels, one instrument, one packed pattern, an order list ending in `0xFF` |
| `default-pan-block.s3m` | `defaultpan == 252` and the 32-byte block that follows the parapointers |
| `sixteen-channels.s3m` | sixteen channels, two patterns, two instruments |
| `st300-volume-slides.s3m` | `Cwt/v == 0x1300`, whose volume slides are fast whatever the general flags say |
| `amiga-limits.s3m` | general-flag bit 4, the Amiga period clamp |
| `order-past-the-end.s3m` | an order naming a pattern the file does not have, plus the `0xFE` skip marker |

The owner's five real Scream Tracker 3 modules are **not** duplicated here — they already
live in `crates/starplayer-s3m/tests/fixtures/` and the seeder copies them from there.

## `mtm/`

| File | What it pins |
|---|---|
| `synthetic-golden.mtm` | the C6a golden fixture |
| `minimal.mtm` | one track, one pattern, one sample, four channels |
| `no-samples.mtm` | a module with no sample headers at all |
| `dmp-tempo-split.mtm` | both `Fxx` halves in one row, which selects the Dual Module Player tempo model over MultiTracker's (C4) |
| `thirty-two-channels.mtm` | the widest channel count the format allows |
